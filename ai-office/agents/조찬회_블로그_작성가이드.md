# 조찬회 블로그 글 작성 가이드 (홍보사원)

참고 자료: 네이버 블로그 "CEO 조찬회" 요약글 5편 (430 AI·DeepSeek / 431 비트코인·스테이블코인 / 432 도시·입지 / 433 양자컴퓨터 / 434 리더의 말과 글)

## 입력 → 출력
- 입력: 조찬회 강연 mp3를 변환한 **텍스트 파일(txt/docx)**. (mp3 음성 자체는 처리하지 못하므로 텍스트로 올린다.)
- 출력: 블로그용 요약글 1편 → **gyn3751@ksa.or.kr 로 이메일 발송** (되묻지 않고 발송).
  - 메일 제목: `[조찬회 블로그 초안] <글 제목>`
  - 본문: 네이버 블로그에 바로 붙여넣을 수 있는 서식(가운데 정렬, 굵게). 같은 내용을 일반 텍스트로도 함께 넣는다.
  - 본문 끝에 `※ 확인 필요` 목록(강연자 이름·직함, 수치, 연도, 고유명사 중 원문에서 불분명한 것)을 붙인다.

## 글 구조 (두 가지 유형 중 강연 성격에 맞게 선택)

### 유형 A: 인사이트 나열형 (430, 431편)
1. 제목 한 줄: 이모지 + 핵심 주제 (예: `🌎 2025년, AI 경제의 대전환이 시작된다`)
2. 도입 2~3줄: 이번 강연의 의미와 한 줄 메시지, 핵심어는 **굵게**
3. `📍 핵심 인사이트 N가지` (N은 8~10개 안팎)
4. 번호 항목: `1. 소제목(굵게)` + 짧은 문장 2줄 이내
5. 마무리: `경영자와 임원 여러분,` → 방향성을 점검해 보시길 권하는 문장 → `✨"핵심 한 문장"✨`

### 유형 B: 강연자 요약형 (432, 433, 434편)
1. 번호 소제목 4~6개 (`1. 왜 ○○인가?`, `2. 현황과 쟁점` 등)
2. 강연자를 밝힐 때는 `○○○ 교수님/박사님께서는 …` 형태, 직함은 원문에서 확인된 것만 사용
3. 각 소제목 아래 짧은 줄 3~5개, 핵심어는 **굵게**
4. 마지막 소제목: `경영자를 위한 시사점` 또는 `실행 인사이트`, 항목은 `키워드 : 설명` 형식 3~5개

## 문체 규칙
- 개조식 짧은 문장, 한 줄 40자 안팎. 문단 줄글 금지.
- 화살표(→), 콜론(:), 대비(`A vs B`)로 압축한다.
- 숫자·연도·고유명사는 강연에서 나온 그대로 쓴다.
- 분량: A4 1~1.5쪽(참고글과 비슷하게).
- 독자는 경영자·임원. 평가·조언은 "~점검해보시길 추천드립니다" 수준으로 정중하게.

## 지켜야 할 것
- 강연 텍스트에 없는 내용, 수치, 인명을 만들어 넣지 않는다. 불확실하면 `※ 확인 필요`에 적는다.
- 참고글을 복사하지 않는다. 구조와 어조만 따른다. (참고글 431편에는 2번 항목에 무관한 문장이 중복 삽입된 오류가 있으니 그대로 따라 하지 않는다.)
- 정치·투자 권유로 읽힐 수 있는 표현은 강연자의 견해로 귀속하고, 우리 의견처럼 쓰지 않는다.
- 이미지가 필요하면 홍보사원 규칙(브랜드 가이드, 시안 승인)을 따른다. 이 글 자체는 텍스트라 승인 없이 발송한다.
