# AI 사무실 (공공기관 행정용)
내 컴퓨터에서 도는 대시보드. 직원은 전부 내 Claude Code(`claude -p`)로 일해서 API 키가 필요 없어요.

## 직원
| 직원 | 하는 일 |
|---|---|
| 🧑‍💼 실장 | 지시를 하위 업무로 나눠 결재함에 올림 |
| 📝 문서 | 공문·보고서(주간/월간)·기획서·회의록 초안 |
| ✉️ 메일 | 회신 초안, 요약, 분류 (발송은 직접) |
| 📊 데이터 | 엑셀 집계·통계·이상값 점검 |
| 🗓️ 비서 | 할 일·마감 정리, 아침 브리핑 |
| 📮 민원 | 민원 분석, 답변서 초안 |
| 💰 회계 | 예산 집행 현황, 집행내역·증빙 점검 |
| 🔍 검토 | 완료된 업무 카드의 '검토 요청'으로 오타·수치·규정 점검 |

## 실행
1. Node.js 설치, 터미널에서 `claude` 한 번 실행해 로그인
2. `start.bat` 더블클릭 (또는 `node server.js`) → http://localhost:4300
3. 문서를 읽어올 폴더는 기본이 상위 폴더. 바꾸려면 `OFFICE_WORKDIR` 환경변수 지정

## 흐름
지시 입력(또는 '반복 업무' 버튼) → **결재함** 대기 → 내가 승인 → 직원 작업 → `drafts/번호.md` 초안 저장 → 칸반에서 확인 → 필요하면 '검토 요청'.
모든 업무는 승인해야 시작해요. 노션 정리 버튼은 Claude의 Notion 커넥터가 연결돼 있어야 해요.

## 고쳐 쓰기
- 직원 역할/말투/규칙: `agents.js` (`_rules`가 공통 규칙)
- 반복 업무 버튼: `templates.js`
- 문서 폴더에 `위임전결` 이 들어간 xlsx가 있으면 문서·메일·민원·검토 결과 끝에 결재 안내가 붙어요.
- 규칙: 초안만 작성 / 발송·제출·상신 안 함 / 파일 수정 안 함 / 개인정보 마스킹. 하루 한도는 '크레딧 설정'.
- 지원 파일: txt, md, csv, json, xlsx, docx, hwpx (hwp·pdf는 hwpx/docx로 저장해서 사용)
