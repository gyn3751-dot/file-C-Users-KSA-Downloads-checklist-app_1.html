# 총괄실 비서 지침 — 사업군별 매출·이익1 분석 (KSA 대시보드)

## 1. 역할
총괄실 비서는 월별 매출·사업비 RAW 파일을 받아 **사업군별 매출·이익1 분석표**와 **KSA 대시보드 문구**를 정해진 엑셀 틀에 작성한다.
**가장 중요한 산출물은 KSA 대시보드 작성 내용**(목표 대비 / 전년 대비 사유 분석)이다.

## 2. 폴더·파일 규칙
| 구분 | 위치 / 규칙 |
|---|---|
| 작업 폴더 | `Z:\★ AI경진대회\★ksa-work\총괄실\` |
| 입력 | `2025년 사업군별 매출, 사업비(N월).xlsx`, `2026년 사업군별 매출, 사업비(N월).xlsx` (월 2개: 전년·당해) |
| 틀(예시) | `매출실적개별현황리포트_N월누계` 시트 구조 (서식 그대로 유지) |
| 출력 | `총괄실\완료\` 폴더(없으면 생성)에 XLSX 저장, 파일명 `YYYY년 사업군별 매출·이익1 분석(N월)_완료.xlsx` |
| 진행 표시 | 입력/작업 파일명에 **(진행)** 이 있으면 작업 대상. 완료 후 **(진행)→(완료)** 로 이름 변경 |

## 3. 처리 순서
1. **열·행 이름 확인**: 2025 RAW 시트 `사업정리본_이관사업제거`(열: 예산(목), 월, 매출계, 사업비기타), 2026 RAW 시트 `Sheet1`(열: 사업범주 3(목) 내역, 전기일, 매출계, 사업비 기타).
2. **사업군 코드 통일** (아래 4번).
3. **필터**: 양 연도 모두 **1월~대상월** 누계. 월은 2025 = `월` 열, 2026 = `전기일`의 월(`기간/연도` 문자열도 가능, 숫자로 읽으면 `2026.010`이 `2026.01`이 되어 1월과 혼동되므로 반드시 문자열로 읽을 것).
4. **합산**: 사업군별 매출계, 사업비기타 합산 → **이익1 = 매출 − 사업비기타**.
5. **계산**: 이익률(이익1÷매출), 전월 대비(당월 vs 전월 단월), 전년 동월 대비(2026.N월 vs 2025.N월), 누계 전년 동기 대비. 증감액·증감률 모두 산출. 분모가 0이면 `-`.
6. **틀에 입력**: 지정 셀에만 값 입력, 서식·병합·색상 유지. 합계·증감은 수식 사용.
7. **비고/사유 작성** (5번), **대시보드 문구 작성** (6번).
8. **검증** (7번) 후 `완료` 폴더에 저장.

## 4. 사업군 코드 통일표
| 2025 RAW | 2026 RAW | 통일명 |
|---|---|---|
| 서비스지수 | 지수 | 지수 |
| 조찬 | 경영자조찬회 | 경영자조찬회 |
| 현장교육(OJT) | OJT | OJT |
| 공개교육, 사내교육, 자격교육, 포럼및세미나, 해외공개연수, 포상, 해외위탁연수, 일반연구 | 동일 | 동일 |

* 2026 RAW 마지막의 `총 액 :` 합계 행은 **제외**(포함 시 이중집계).
* 2025는 이미 인문경영(이관사업) 제외된 시트를 사용한다.
* **2025 요약 피벗(Sheet2) 값은 1~12월 성격이라 비교값으로 쓰지 말 것** — 반드시 RAW를 1~N월로 필터해 재집계.

## 5. 비고 작성 규칙 (증감률에 큰 영향을 준 내역·빈 값)
* 증감액이 3천만 원 이상이면서 총 증감액의 20% 이상인 사업군 → 영향을 준 **행사/과정명 상위 2개와 금액** 기재 (`내역` 열 기준, 연도 숫자 제거 후 비교).
* 값이 비어 있는 경우 명시: 해당 월 실적/전년 데이터 없음, 사업비 미발생, 전월·전년 값 없음(증감률 산출불가).
* 매출이 음수(취소·환불)면 이익률·증감률 해석 주의 표기.
* 사업이 바뀐 경우(예: 2025 KS-WEI → 2026 한국웰니스지수)는 코드 통일하지 않고 차이로 설명.

## 6. KSA 대시보드 작성 (최우선)
구성은 틀의 `Q2` 병합 셀과 사유 박스(`I4`, `L4`, `I20`, `L20`)에 입력한다.
1. **26년도 목표 대비 실적 분석** — 매출 합계/목표/차이/달성률, 미달·초과 사업군 상위(금액, 억 단위 1자리), 사업비·이익1·이익률.
2. **전년 동기 대비 실적 분석** — 매출·이익1 증감(억, %), 증가·감소 상위 사업군, 이익률 변화(%p).
3. **데이터 확인 사항** — 소스 불일치·추정치 미검증 항목.
4. 문구 수치는 **표의 계산값과 일치**해야 하며, 불일치 시 표 기준으로 수정하고 3번에 사유 기재.
5. 목표(`누계목표`)는 틀의 값을 사용. **이익1 목표·연간 추정은 RAW에 없으므로 임의 산출 금지**, '확인 필요'로 표시.

## 7. 검증 체크리스트
- [ ] 사업군 합계 = RAW 총합 (2026 N월 누계 매출·사업비 / 2025 1~N월)
- [ ] 이익1 = 매출 − 사업비 (사업군별 일치)
- [ ] 합계·증감 셀이 수식이며 오류(#REF 등) 없음
- [ ] 대시보드 문구 수치 = 표 수치
- [ ] 서식(병합, 색상, 숫자형식) 틀과 동일
- [ ] 출력은 `완료` 폴더, 파일명 `_완료`, (진행)→(완료) 변경
