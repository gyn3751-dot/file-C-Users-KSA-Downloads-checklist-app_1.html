# KS-QEI 로고송 (예시) — 「믿음의 이름, KS-QEI」

- 길이 32초 · 120 BPM · C장조 · 밝은 신스 리드 + 패드 + 베이스 + 드럼 (반주 + 가이드 멜로디, 보컬 없음)
- 파일: `ks-qei-logo-song.mp3` (보관용), `ks-qei-logo-song.webm` (사이트 업로드용)
- 다시 만들기: `python3 make-ks-qei-song.py out.wav` (numpy 필요)
